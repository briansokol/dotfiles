# suggested commands
- `./bootstrap.sh` — full bootstrap for the current machine.
- `./bootstrap.sh --no-packages` — stow + plugin bootstrap only.
- `./bootstrap.sh --packages-only` — install packages only.
- `stow --no-folding <package>` — install a package.
- `stow --delete <package>` — uninstall a package.
- `update-all` — update system and dotfiles-related dependencies.
- `update-all --sync-packages` — install newly added manifest packages.
- `git log --oneline -5` — recent commit style/context.
