# style and conventions
- Prefer minimal, focused changes that preserve existing package structure and Stow layout.
- Configs follow XDG-style placement under `package/.config/...` when applicable.
- Existing repo guidance emphasizes small correct edits, preserving established patterns, and avoiding unnecessary refactors.
- For Hyprland-related configs in this repo, Catppuccin theming is shared via adjacent config files such as `mocha.conf`.
